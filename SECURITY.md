# Security Policy

## Reporting a Security Issue

If you find a security issue in Watchman, please do not open a public GitHub issue with sensitive details.

Instead, report it privately to the maintainers at [alnoman.dhoni@gmail.com](mailto:alnoman.dhoni@gmail.com) or [wrafiz.k@gmail.com](mailto:wrafiz.k@gmail.com).

Please include:

- A clear description of the issue
- Steps to reproduce it
- Your Windows version
- Your Watchman version
- Any relevant screenshots, logs, or error messages

## Scope

Security reports may include issues related to:

- Local data handling
- Update behavior
- External links opened by the app
- Unexpected network activity
- App permissions or Windows integration behavior

Watchman is a local-first desktop app. Traffic history is stored locally on the user's PC.

## Response

Security reports will be reviewed as soon as possible. If the issue is confirmed, a fix will be prepared and released through the normal Watchman release process.
